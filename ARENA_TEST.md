# Wizardry test build 0.135

Open `arena.html` (the root page redirects here). See README.md for the current setup, build, deck and online-lobby rules.

For Creeping Croc: create a wizard with Water plus a second mastery, fill a legal 24-card grimoire including Croc, allocate all 20 points and save. Start a practice duel; Croc is in the opening hand when included in the grimoire. Its base damage is 800 before the three damage variants and Water mastery. Fear can only skip an action still pending in the current round.

To team up with friends: create an online lobby, share the invitation, choose the same team, add randomized CPUs to opposing seats, ready up and let the host start. The host must keep the game page open.
